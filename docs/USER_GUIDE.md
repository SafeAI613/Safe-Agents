# מדריך למשתמש – Safe Agents

Safe Agents היא אפליקציה למחשב שבה מתקינים אייג'נטים (עוזרים חכמים לתחום מסוים) ומשתמשים בהם בשיחה.

## התקנה

1. מורידים את קובץ ההתקנה מעמוד ה-Releases (‏Windows: ‏`.msi` או `.exe`; ‏macOS: ‏`.dmg`; ‏Linux: ‏`.deb` או `.AppImage`).
2. מתקינים ופותחים את האפליקציה.
   - אם Windows מציג "Windows protected your PC": ‏"More info" ← "Run anyway" (עד שהאפליקציה תיחתם בתעודה).

## הפעלה ראשונה

האפליקציה מבקשת **מפתח OpenRouter** – דרכו כל האייג'נטים משתמשים במודלים.
1. יוצרים מפתח בחשבון OpenRouter.
2. מדביקים אותו ולוחצים "שמירה והמשך". המפתח נבדק מול OpenRouter ונשמר במאגר הסיסמאות המאובטח של מערכת ההפעלה.

## התקנת אייג'נט

1. **חנות** ← בוחרים אייג'נט ← **התקנה**.
2. לפני ההתקנה מוצגות ההרשאות שהאייג'נט מבקש (למשל קריאת קבצים או הרצת קוד). מתקינים רק אם מתאים.
3. ההתקנה הראשונה במחשב מורידה גם את Python – זה לוקח כמה דקות. התקנות הבאות מהירות יותר.

**התקנה מקובץ ZIP** (בחנות, למעלה): למפתחים או לאייג'נט שקיבלתם ישירות. אייג'נט כזה לא עבר את בדיקות הקטלוג.

## שיחה

- **האייג'נטים שלי** ← **פתיחת שיחה**. בפעם הראשונה האייג'נט עולה תוך כמה שניות.
- כותבים בקשה ולוחצים Enter (או "שליחה"). Shift+Enter – שורה חדשה.
- מתחת לשיחה מופיע מה האייג'נט עושה כרגע: "האייג'נט עובד", "מנסח תשובה", "מפעיל כלי".
- **בקשת אישור**: לפני פעולה רגישה האייג'נט עוצר ומציג מה הוא מתכוון לעשות. לוחצים "אישור" או "דחייה".
- **קבצים**: "צירוף קובץ" או גרירה לתיבת ההודעה (רק סוגי קבצים שהאייג'נט תומך בהם).
- **שיחות קודמות**: ברשימה "שיחות" בראש המסך. השיחות נשמרות גם אחרי סגירת האפליקציה ועדכון האייג'נט.
- **עזרה**: מה האייג'נט יודע לעשות ודוגמאות – לחיצה על דוגמה מעתיקה אותה לתיבת ההודעה.
- **ייצוא שיחה**: שומר את השיחה כקובץ בתיקיית ההורדות.
- **עלות**: מתחת לשיחה – עלות וכמות טוקנים. סיכום לפי מודל: הגדרות ← שימוש ועלויות.

## מפתחות נוספים

יש אייג'נטים שצריכים מפתח משלהם (למשל לחיבור לשירות חיצוני): האייג'נטים שלי ← **מפתחות**. המפתחות לא מוצגים שוב אחרי השמירה, ונמחקים עם הסרת האייג'נט.

## עדכונים והסרה

- כשיש גרסה חדשה – מופיע "עדכון זמין" בכרטיס האייג'נט. העדכון נעשה מהחנות, והשיחות נשמרות.
- **הסרה** מוחקת את האייג'נט, הקבצים שלו והמפתחות שלו.

## פתרון בעיות

| מה רואים | מה לעשות |
|---|---|
| "מפתח ה-API נדחה" | בודקים שהמפתח הועתק במלואו; אפשר להחליף בהגדרות |
| "נגמר הקרדיט בחשבון OpenRouter" | טוענים קרדיט בחשבון, או בוחרים מודל חינמי ברשימת "מודל" |
| "חסרים מפתחות" | האייג'נטים שלי ← מפתחות |
| "אין חיבור לקטלוג" | בדיקת אינטרנט; בינתיים מוצג הקטלוג האחרון שנשמר |
| האייג'נט לא עולה | האייג'נטים שלי ← **יומן** – מציג את השגיאה של האייג'נט |
| משהו אחר | הגדרות ← אודות ותמיכה ← **העתקת פרטים לתמיכה** (לא כולל מפתחות) ושליחה למפתחים |

## פרטיות

- המפתחות נשמרים רק במאגר הסיסמאות של מערכת ההפעלה ונשלחים רק לשירות שאליו הם שייכים.
- תוכן השיחות נשלח למודל דרך OpenRouter. ל-LangSmith – רק אם הפעלתם ניטור בהגדרות.
- האפליקציה לא שולחת נתוני שימוש.
